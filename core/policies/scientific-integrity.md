# Scientific Integrity

The research argument is Problem → Gap → Idea → Evidence → Impact.
Keep 2–4 concrete, verifiable contribution claims. Map each research question and
claim to an experiment, figure, table, derivation, theorem, simulation, or other
traceable evidence. Record the mapping in `notes/evidence-matrix.md`.

Never fabricate experiments, numerical results, datasets, simulations, baseline
results, references, authors, DOI values, or BibTeX entries. Use explicit TODOs
and evidence gaps. An illustrative diagram is not experimental evidence.

Classify missing evidence as **blocking**, **important**, or **optional**. Distinguish
planned validation from completed validation, and keep assumptions and limitations
visible. Preserve scientific meaning when editing existing material.

Plan figures and tables before long prose. Prefer drafting Method → Experiment
setup → Results → Introduction → Related Work → Abstract → Conclusion so summary
claims describe evidence that actually exists. Detailed planning and drafting
procedures are in `core/workflows/idea-to-paper.md` and
`core/workflows/paper-production.md`.
