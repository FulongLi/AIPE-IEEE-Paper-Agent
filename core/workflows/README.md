# Canonical Workflows

`core/SKILL.md` routes tasks to these workflows. Policies live in `core/policies/`.
Every workflow has one maintained source; `scripts/package-release.py` generates
portable references. The power-electronics collection-maintenance procedure is
owned by its optional domain pack under `domains/power-electronics/literature/`.

Start with `core/workflows/idea-to-paper.md`, proceed through paper production and
manuscript generation, then citation verification and publication audit. Section
writing guidance and reviewer responses remain available as dedicated workflows.
